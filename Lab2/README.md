运行依赖为 NumPy、pandas 和 Matplotlib，最低版本见 `requirements.txt`。从包含 `Lab2/` 的项目根目录执行：

```powershell

python run_all.py
python verify_results.py
```

以下路径均相对于 `Lab2/`，无需使用特定名称的虚拟环境。

## 实验约定

固定外层随机种子 42，按行随机划分 80% 训练和 20% 测试（测试数向下取整）。岭回归与多项式模型在外层训练集内用种子 43 再划出 20% 验证集；选择参数后，用完整外层训练集重新拟合。标准化统计量只来自当前拟合训练集。测试集用于最终比较，不用于选择超参数。

任务 3 用固定迭代预算、训练损失及距闭式解损失不超过 1e-4 的首次迭代数比较学习率。BGD 目标为 MSE，所以梯度含系数 2。岭回归目标为 SSE + λ||w||²，截距不惩罚，主实验固定 λ=1，扫描中包含 λ=0 作为普通最小二乘基线。

多项式主实验对全部 11 个特征生成含交互项的 1、2、4 阶特征，分别为 11、77、1364 个非恒定特征；SVD 最小二乘避免显式求逆的数值问题。另外使用同一葡萄酒数据中的 alcohol 单特征绘制可解释的一维拟合曲线。原拓展模板指定第一个数据集，与实验报告冲突，已按报告改为白葡萄酒数据。`poly_demo.csv` 不参与评分任务。

本地白葡萄酒数据含重复行，按照要求保留并随机按行切分。报告列出跨集合相同行的数量与评估局限。四阶多项式的极大测试 MSE 是真实运行结果，完整保留；二阶在验证集最优，一阶在此次测试集最优，不能据此用测试集重新调参。
